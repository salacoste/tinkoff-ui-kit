## 3. Состав волны (спеки по заземлённым)

1. **26.1 tk-range-slider** (M) — интерактивный трек с ручкой,
   min/max/step, aria-valuenow/valuetext, keyboard (стрелки/гоме/энд),
   value-formatter, хук высоты/радиуса. Молд прогресс-бара для
   трека + tk-input для клавиатурного контракта.
2. **26.2 tk-switch** (S/M) — boolean-тумблер; роль switch
   (APG), aria-checked, disabled, размерный ряд по админ-замерам;
   визуальная форма — по повторной пробе админа (AC-гейт).
3. **26.3 tk-avatar** (S) — roundel с фото/инициалами/плейсхолдером;
   замеры 20px (byline) / 45px (news) / круглые админ-фид; role=img
   self-assert, lazy-энфорсмент (молд tk-figure), sizes via property.
4. **26.4 OTP-code** (S/M) — вариант `code` у tk-input (gap-6
   формулировка: 4 ячейки, авто-переход, вставка-разделение);
   включён рулингом-2 после аудита.

**HOLD (не спекаются):** spinner, textarea — оба ждут живой паттерн.
Разблокировщик: капчуры 24T (терминал = кандидаты на оба: спиннеры
загрузки и поля ввода). Внесены в чек-лист 24T как явные цели.
