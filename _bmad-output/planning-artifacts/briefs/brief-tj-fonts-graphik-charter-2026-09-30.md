# БРИФ — решение о шрифтах ТЖ: Graphik / Charter (очередь мейнтейнера §4d, 2026-09-30)

> Для мейнтейнера. Решение по пункту (d) очереди v1.4.0: «Graphik/Charter
> лицензии — решение о поставке ТЖ-шрифтов». Оркестратор решения НЕ
> принимает — ниже входные данные и опции. Пока решение не принято,
> действующая модель = ОПЦИЯ A (нуль-шрифтовая, уже в v1.4.0).

## Текущее состояние (как отгружено в v1.4.0)

- Слоты (единственный источник — `packages/tj-tokens/src/tokens.css`):
  - `--tj-font-ui: Graphik, Inter, -apple-system, system-ui, …` — гротеск
    (шапки/H2/display);
  - `--tj-font-reading: Charter, "Bitstream Charter", "PT Serif", Georgia, serif` —
    чтение (лид/абзац).
- **Zero-fonts инвариант:** ни один ТЖ-пакет не бандлит шрифтовых
  бинарников; тестом; лицензируемый путь задокументирован (docs: ТЖ
  getting-started + token-reference; DESIGN/TOKENS) — потребитель приносит
  файлы сам, лицензии мейнтейнера не передаются. ТЖ-пакеты — чистый MIT.
- Прецедент банковской стороны: DaytonaSans/DaytonaPragma — отдельно
  лицензированные бинарники © Monotype/ParaType, НЕ MIT, права определяет
  только `packages/tokens/fonts/LICENSE-FONTS.md` (модель с v1.0.0).

## Что нужно решить

Поставлять ли шрифтовые бинарники ТЖ-семейства (и если да — как), либо
остаться на нуль-шрифтовой модели с систем-first фолбэками.

## Опции

### A. Остаться на zero-fonts (статус-кво, рекомендовано до спроса)

- Стоимость: 0; юридически чисто (MIT-пакеты без бинарников); фиделити:
  без файлов потребитель видит Inter/PT Serif — метрически близкие
  фолбэки, выбраны сознательно (15.3, закрытие OQ-8).
- Минус: «коробочный» потребитель не получает точный референсный вид без
  своего шага установки шрифтов.

### B. Поставлять бинарники отдельным НЕ-MIT пакетом (модель Daytona)

- `pillkit-tj-fonts`: @font-face + woff2, своя LICENSE-FONTS.md, вне MIT-
  тройки; тройка остаётся zero-fonts (инвариант и тест сохраняются).
- Требует: (1) приобретение/подтверждение прав на веб-embedding и
  распространение как части кита: **Graphik — Commercial Type (платная)**;
  **Charter — проверить версию**: в стеке уже стоит «Bitstream Charter» —
  Bitstream/Charter (Matthew Carter) исторически распространяется СВОБОДНО
  (разрешает редистрибуцию) — если референсный Charter метрически совпадает
  с Bitstream Charter, чтение можно поставить почти бесплатно (проверка
  лицензии и совпадения — на мейнтейнере); (2) бамп OQ-10-поезда (новый
  пакет в version-бампе, CHANGELOG); (3) доки-рецепт «шрифты одной строкой»;
  (4) тесты-визуал остаются на фолбэках (иначе базлайны机器но зависят от
  установки — сегодняшний пин систем-first не трогаем; в тексте выше имелось в виду «машинно зависят»).

### C. Гибрид: рецепт-пакет без бинарников

- `@font-face`-декларации + инструкция в отдельном лёгком пакете/разделе
  (бинарники потребитель кладёт сам по своей лицензии). Дешёвое улучшение
  DX поверх A без юридических шагов.

## Рекомендация оркестратора (не решение)

**A сейчас, C при первом вопросе потребителя, B — только если появится
реальный потребительский спрос и подтверждённые права** (Charter/Bitstream —
проверить первым, там вероятен бесплатный путь; Graphik — платный и без
прав не объезжается). Изменение слотов/добавление пакета = отдельная стори
по циклу §5 HANDOFF (токен-источник + gen:tokens + доки + CHANGELOG).
