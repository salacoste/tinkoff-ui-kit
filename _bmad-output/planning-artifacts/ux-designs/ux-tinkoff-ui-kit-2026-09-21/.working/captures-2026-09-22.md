# Capture observations — tbank.ru reference pack (2026-09-22, Story 2.0)

Provenance: `.playwright-cli/captures/` (see INDEX.md for file → component → URL map).
Method: zai-mcp-server `analyze_image` vision pass on each capture (harness is text-only for images),
cross-checked where possible with `magick` pixel sampling and `playwright-cli eval` computed styles
(noted per value). Element screenshots are exact element bounds at DPR 1 → image px = CSS px.
All vision hex/px values are estimates with ± ranges; uncertain values are flagged.
These are observations only — DESIGN.md/EXPERIENCE.md values are corrected at stories 3.6/5.6, never here.

Shared reading notes: a floating cookie-consent card appears bottom-right in `footer.png` and
`application-form-full.png` (capture artifact — exclude when sampling); the sticky site header is
visible inside `footer.png` at y≈600. The form panel sits on a light-gray band (vision: ~#EBEBEB)
while the rest of the page is white.
