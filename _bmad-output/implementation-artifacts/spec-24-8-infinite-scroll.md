# Spec 24.8 — infinite-scroll лента (pattern wave 24b)

- **status:** DRAFT 2026-10-03 (AC frozen; исполнения нет)
- **baseline_commit:** 977fa40
- **epic note:** Epic 24, brief `brief-epic-24-pattern-wave-2026-10-03.md` (Решение 1,
  24b-хвост; P7 включён решением ассистента).
- **grounding:** gap-2 «Пульс/новости»: одноколоночная бесконечная лента
  карточек — НЕТ пагинации, «Показать ещё», футера; страница кончается
  посреди карточки (news 21 694 px / pulse 16 515 px). Анатомия карточки:
  строка автора (аватар, имя канала, галочка, серый таймстамп), жирный
  заголовок, опциональная широкая обложка, строка тела; ряд тикер-чипов
  (2–3 + overflow «Ещё N»); экшн-бар над тонким разделителем
  («Нравится»/«Комментировать»/share). Отчёты:
  `.playwright-cli/captures-v4/invest/reports/gap-2-instrument.md`.
- **решение ростера:** ПАТТЕРН-СТОРЯ в docs-шоукейсе invest-паттернов на
  СУЩЕСТВУЮЩИХ атомах: tk-quote-chip (pill — тикер-чипы, overflow — «Ещё
  N»), tk-article-card НЕ используется (карточка ленты — потребительская
  композиция: gap-2 пин «uniform anatomy»), экшн-бар — потребительские
  кнопки-ссылки; сентинел-подгрузка — стори-логика демо-консьюмера
  (IntersectionObserver), кит НЕ получает infinite-scroll атом (лента —
  потребительский рецепт, как сам gap-2 и классифицировал).

## AC (frozen)

1. **Композиция.** Лента из существующих атомов (tk-quote-chip ×2 формы)
   + потребительская карточка; без новых компонентов/токенов/пинов.
2. **Рецепт сентинела.** Демо-лоадер стори: наблюдатель края ленты
   аппендит следующий батч в конец, аппенд объявляется aria-live
   («Загружено ещё N»); НЕТ кнопки «Показать ещё», НЕТ футера под лентой
   (сам предмет паттерна); конец демо-ленты — честная терминальная нота.
3. **Детерминизм базлайна** (урок 24.6, генерализованный): канва в покое
   НЕ должна зависеть от тайминга наблюдателя — стори-драйвер доводит
   ленту до детерминированного состояния на маунте (первый аппенд
   выполняется драйвером, дальнейшие — по скроллу в интерактиве); в
   базлайне ровно начальный + один аппенд-батч + терминальная нота.
4. **A11y.** Список — role=list/listitem ИЛИ семантическая разметка
   статей; заголовки карточек — h3 под единственным h1 канвы; axe обеих
   тем; клавиатурный чек-лист в видимой прозе.
5. **Обе темы** без правок состава; ПД-гейт: каналы, тексты, числа —
   вымышленные.
6. **Цикл.** гейты → pathspec → zero-in-flight → push → CI-вердикт →
   close-out штамп; урок 23.4 (импорты/свип/axe в первом минте).
