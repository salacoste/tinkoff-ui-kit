## AC (frozen)

1. **Композиция.** Сторя «Торговый бланк» в docs (секция invest-паттернов):
  сторона — tk-segmented-radio «Купить / Продать» (переключатель стороны,
  состояние стори-уровня); сумма — tk-input (суффикс валюты, AC4);
  счётчик лотов — мини-паттерн «− значение +» из кнопок кита (замер
  недоступен — китовый регистр: цели ≥44px, значение по центру);
  CTA — tk-button primary (жёлтая пара) с текстом по стороне;
  «Добавить в портфель» — слот-кнопка-звезда (молд 22.5, consumer-state);
  ИИР-приписка — tk-note (21.4, info-тон: «Не является индивидуальной
  инвестиционной рекомендацией» — формулировка-молд из живых каптур,
  легальная формула, не ПД-контент).
2. **A11y паттерна.** Группа стороны — radiogroup с подписью; счётчик —
  реальные кнопки с aria-label («добавить лот»/«убрать лот») и живым
  значением; сумма — label+input связка; всё — механизуемые контракты
  атомов, паттерн их только компонует. Пин — в notes стори (чек-лист
  клавиатуры), прогон — axe обеих тем.
3. **Данные.** ВЫМЫШЛЕННЫЕ (ПД-гейт): инструмент, цены, суммы; расчёт
  «итого» в демо — стори-логика (демо консьюмера, кит не считает).
4. **Малые расширения (только при необходимости).** Кандидат — суффикс
  tk-input (₽/пт в поле суммы): если принимается — VARIANT tk-input с
  юнит-тестами и gen; иначе суффикс — внешняя подпись в паттерне. Решение
  фиксируется в execution record с обоснованием.
5. **Стори/базлайны.** Сторя в обеих темах, базлайны НОВЫЕ; полный
  compare зелёный.
6. **Цикл.** gen (если AC4 принят) → гейты → pathspec → zero-in-flight →
   push → CI-вердикт → close-out штамп.
