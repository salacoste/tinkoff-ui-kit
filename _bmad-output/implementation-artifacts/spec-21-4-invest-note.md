## AC (frozen)

1. **Атом.** `tk-note` (`packages/components/src/note/`): свойство `icon`
   (дефолт ⓘ-круг, как KV-список 21.x-материала; или без иконки — замер),
   default slot (текст), опциональное `collapsible` — хвост «Показать/
   Скрыть» текст-ссылкой; свойства тона `tone="neutral | info"`
   (нейтральный серый — основной заземлённый; info-синий — currency).
   Деструктив/успех НЕ заводим (не заземлено).
2. **Раскрытие.** `collapsible` → clamp текста (2–3 строки) + «Показать»;
   механика = тот же disclosure-контракт, что tk-accordion-item
   (aria-expanded на ссылке-кнопке, без aria-controls — прецедент);
   переиспользование внутреннего механизма приветствуется (приватный
   хелпер или общий mixin — решение при исполнении, БЕЗ кросс-импорта
   компонентов: import-boundaries).
3. **Токены.** `--tk-note-*` (заливка нейтральная, радиус, текст-тон);
   info-тон = существующий link/info цвет, НЕ минтить нового. Жёлтого
   ноль.
4. **Стори.** песочница + демо «не является индивидуальной инвестиционной
   рекомендацией» (заземление каталогов; текст вымышленный по закону ПД
   — без дословных юридических формул с числами) + collapsible ×2
   состояния + dark.
5. **Тесты.** Unit: тон-классы, collapsible toggle, aria-expanded,
   css-пины; hidden-guard рост; axe; визуальные базлайны НОВЫЕ, полный
   compare зелёный.
6. **Цикл.** gen → гейты → pathspec-коммит → zero-in-flight → push →
   CI-вердикт по run id → close-out штамп.
