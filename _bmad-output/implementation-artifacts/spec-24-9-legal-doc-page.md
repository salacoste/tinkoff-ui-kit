## AC (frozen)

1. **tk-breadcrumb атом.** Полный каталожный цикл: хуки, юниты
   (семантика nav/ol/li/aria-current, stateless-пин, структурные пины),
   CEM → React wrapper → docs search row → ростер пакета; скрытые
   щиты hidden-guard — ростер +1 (осознанный бамп пина).
2. **Legal-проза.** Регистр ~16px (body-m) с записанным отклонением от
   Charter-шкалы tj-prose (запрещён сам инструмент, не только тема);
   перечисления нумерованные/буквенные; инлайн tk-link на токенах;
   НЕТ h2/h3 — жирные лиды абзацев (живой пин); единый h1 канвы.
3. **Doc-строки.** Два блока: svg-иконка (currentColor, декоративна,
   aria-hidden) + жирный заголовок-ссылка + серая мета-строка; ряд —
   потребительский CSS, hover/focus видны, клавиатура — таб по ссылкам.
4. **A11y.** axe обеих тем; порядок заголовков; чек-лист клавиатуры в
   видимой прозе; «Скачать PDF» — реальная ссылка-кнопка (демо без
   выгрузки — тост).
5. **Обе темы** без правок состава; ПД: формулировки документов
   ВЫМЫШЛЕННЫЕ (структура жанра, не живые тексты).
6. **Цикл.** гейты → pathspec → zero-in-flight → push → CI-вердикт →
   close-out; урок 23.4 (импорты/свип/axe в первом минте).
