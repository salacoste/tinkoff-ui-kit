## AC (frozen)

1. **Атом.** `tk-instrument-hero` (`packages/components/src/
  instrument-hero/`): props `name` (заголовок), `ticker` (вторичная
  строка/ISIN), `tone="stock|dark|light"` (3 градиентных семейства:
  зелёный акции/облигации, тёмный ETF/фьючерс, светлый валюта —
  замер градиентов при исполнении, ССЫЛКАМИ на токены где совпадает,
  иначе инлайн-градиенты с хуком переопределения); слот `metric`
  (лейбл+значение: «Доходность…» −12,86% / «Тип контракта» Расчетный
  — или ПУСТО, etf/currency без метрики); слот `logo` (круглый
  раундэл/эмблема/флаг); слот `action` (звезда-favorite — кнопка
  потребителя, кит только располагает).
2. **Градиенты.** Прозрачно записанные в шапке css.ts замеры всех
  4 живых градиентов; дефолты = ближайшие токены где байт-близко,
  девиации честно фиксируются (молд точек карусели: gray-200 ±3).
3. **A11y.** h-уровень заголовка = слот-контент потребителя (кит
  рендерит div, НЕ h1 — consumer-семантика; живой баг пустых h1
  записан в negatives, кит делает правильно); region НЕ нужен;
  звезда = слот-кнопка со своей семантикой.
4. **Стори.** песочница 3 тона × с/без метрики + демо-страница
  «облигация» (bond-заземление, вымышленный выпуск) + API. Dark —
  штатные пары (тёмный тон в dark остаётся собой — замер).
5. **Тесты.** Unit: тона-классы, слоты, пустой metric, css-пины
  (в т.ч. NOT h1); hidden-guard рост; axe; базлайны НОВЫЕ, полный
  compare зелёный.
6. **Цикл.** gen → гейты → pathspec → zero-in-flight → push →
   CI-вердикт → close-out штамп.
