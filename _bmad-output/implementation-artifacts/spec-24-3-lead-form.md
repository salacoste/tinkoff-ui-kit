# Spec 24.3 — лид-форма: телефон + согласие + CTA, standalone и embed (pattern wave 24a)

- **status:** DRAFT 2026-10-03 (AC frozen pending «go»; исполнения нет)
- **baseline_commit:** 331a246
- **epic note:** Epic 24, brief `brief-epic-24-pattern-wave-2026-10-03.md` (Решение 1).
- **grounding:** gap-6 ×3 (hero-форма «Начните инвестировать», «Оформить
  заявку» iframe-shell 900px, create-account/create-iis) + gap-3 (hub):
  телефон + CTA (+ имя в embed-варианте), чекбокс согласия, жёлтая
  кнопка, «Назад» arrow-link. Атомы покрыты (tk-input type=tel,
  tk-checkbox, tk-button, tk-link); отсутствует РЕЦЕПТ макета.
- **решение ростера:** ПАТТЕРН-СТОРЯ с двумя вариантами в одной канве:
  (а) standalone hero-кластер (заголовок + форма + сайд-подпись) —
  молд business-landing формы; (б) embed-обёртка (узкая 320px карта
  «iframe-вид», без hero-хрома). Состояние согласия/валидации —
  стори-логика (CTA блокируется без чекбокса, локальная валидация
  телефона маской демо). Отправка НИКУДА не идёт — тост «Заявка
  отправлена (демо)».

## AC (frozen)

   «Назад» — tk-link.

   чек-лист клавиатуры в прозе; axe обеих тем.

5. **Стори/базлайны:** 1 новая сторя, полный compare зелёный; урок 23.4.
6. **Цикл.** гейты → pathspec → zero-in-flight → push → CI-вердикт →
   close-out штамп.
