## AC (frozen)

1. **Атом.** `tk-rating` (`packages/components/src/rating/`): свойство
   `value` (0–5, шаг 0.5 разрешён схемой, живое = целые; замер при
   исполнении), `count` (опционально — число оценок рядом, серым,
   reviews-заземнение), `size` НЕ заводим (один размер; иконка-звезда
   SVG inline, молд существующих chevron-иконок пакета).
2. **A11y.** `role="img"` + `aria-label="Рейтинг N из 5"` (или
   aria-hidden при `count`-тексте рядом — замер живого: звезды без
   текста-дубля; решение в таблице токенов). НЕ интерактив: tabindex
   нет, focus нет.
3. **Токены.** `--tk-rating-*` (звезда-заливка жёлтая — существующий
   жёлтый кита, НЕ новый минт; пустая звезда — нейтраль; размер).
   Частичная звезда: клип-путь по проценту ширины (без второго SVG).
4. **Стори.** песочница (value 0/0.5/3/4.5/5 + count) + демо «рейтинг
   облигации» (строка имя+ISIN+звезды, заземление bonds) + dark.
5. **Тесты.** Unit: value→заполнение (включая 0.5-клип), aria-label
   строка, count-режим, css-пины; hidden-guard; axe (role=img с именем);
   визуальные базлайны НОВЫЕ, полный compare зелёный.
6. **Цикл.** gen → гейты → pathspec-коммит → zero-in-flight → push →
   CI-вердикт → close-out штамп.
