## AC (frozen)

1. **Plan-cards.** Ряд из 3 карточек: имя плана, крупный fee-заголовок,
   чек-лист фич (иконки-галочки консьюмера), CTA tk-button; существующие
   атомы, ноль правок.
2. **Матрица.** CSS-grid (НЕ table-элемент): первая колонка — фича,
   дальше колонки планов; tab-переключение секций (tk-tabs); aria:
   role=table/row/columnheader/cell на grid-divs (APG table-на-div) или
   обоснованный отказ в execution record.
3. **A11y.** Порядок заголовков (h2 секции), матрица объявляема
   экранным читалкой (role-сетка + scope), axe обеих тем.
4. **Обе темы** без правок состава; full-bleed канва-молд 23.3.
5. **Стори/базлайны:** 2 новые стори (планы + матрица), полный compare
   зелёный; урок 23.4 (импорты/свип/axe в первом минте) обязателен.
6. **Цикл.** гейты → pathspec → zero-in-flight → push → CI-вердикт →
   close-out штамп.
