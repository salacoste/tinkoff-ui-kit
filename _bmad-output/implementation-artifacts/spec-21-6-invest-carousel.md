## AC (frozen)

1. **Атом.** `tk-carousel` (`packages/components/src/carousel/`): default
   slot = карточки; механика — scroll-snap контейнер (нативный скролл,
   НЕ transform-карусель), chevron-кнопки prev/next (круглые, белые,
   тень dropdown; появление по ховеру фокуса рейла — замер живого),
   опциональная точечная пагинация `dots` (активная точка жёлтая —
   существующий жёлтый). Ширина карточки — консьюмерская (слот сам её
   несёт); атом управляет только хромом и скроллом.
2. **Поведение.** Chevron скроллит на ширину вьюпорта рейла (поведение
   «страница», замер живого); disable-состояние краёв (первая страница —
   prev скрыт/затемнён, замер); клавиатура: карточки табаются сами
   (нативно, они ссылки), кнопки — кнопки; фокус-в-рейл → стрелки
   Left/Right скроллят (нативный скролл-контейнер уже так умеет —
   проверить, не дублировать).
3. **A11y (дифференциатор кита).** `role="region"` + `aria-roledescription=
   "карусель"` + `aria-label` (требует свойства `label`); кнопки несут
   aria-label «Назад/Вперёд»; БЕЗ aria-live на скролле (шум); автоплей
   НЕТ (не заземлено — и правильно). Точки-пагинация: aria-hidden
   декоративна, роль выбора не несут (замер живого: точки не кликабельны).
4. **Токены.** `--tk-carousel-*` (chevron-заливка/размер/тень, зазор,
   точка активная/пассивная); тень = существующий dropdown-токен.
5. **Стори.** песочница (8–12 карточек, логи disable-краёв) + демо
   «Похожие акции» (карточки инструментные — имя+цена+Δ%) + демо
   «Недавно просмотренные» (мини-карточки 150×110) + dots-вариант +
   dark. Карточки в демо — light-DOM заглушки стори (атом карточек
   НЕ рисует).
6. **Тесты.** Unit: region/aria, disable-логика краёв (моки scrollWidth/
   scrollLeft), dots-рендер, css-пины; hidden-guard; axe на песочнице;
   визуальные базлайны НОВЫЕ (+ регион-спека на открытое состояние НЕ
   нужна — нет top-layer; chevron-кнопки в потоке), полный compare зелёный.
7. **Цикл.** gen → гейты → pathspec-коммит → zero-in-flight → push →
   CI-вердикт → close-out штамп.

## Out of scope

- Transform/translate карусели, автоплей, loop-бесконечность, свайп-
  жесты отдельно (нативный touch-скролл уже есть), виртуализация длинных
  списков, вертикальные рейлы, бейдж «Еще N» (это контент пост-карточки,
  gap-4), per-page настраиваемый шаг.
