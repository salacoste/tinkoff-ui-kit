## AC (frozen)

1. **Лейаут-рецепт.** Двухколоночная сетка (main широкая + сайдбар 247px —
  ширина живого билета 22.6); collapsing на <1024 (сайдбар под main);
  **sticky-сайдбар** — `position: sticky` паттерн с документированными
  условиями (родитель без overflow-обрезки, top-офсет по замеру хедера);
  реализация — сторя-уровень (CSS-рецепт потребителя), в прозе стори
  зафиксированы ловушки (sticky внутри overflow:auto родителя и пр.).
2. **Сборка.** Полная страница: hero (тоновое семейство по выбору) →
  тулбар таймфреймов (композиция чипов) + tk-chart → «Показатели
  бумаги» (tk-tabs + tk-kv-list с дельта-значениями — токены 22.1/22.2
  в слот-контенте) → «Частые вопросы» (tk-accordion) → новости
  (tk-article-card); сайдбар: билет (22.6) + tk-publisher-header (23.2)
  + сводка-прогноз (tk-feature-card). Все данные ВЫМЫШЛЕННЫЕ (ПД-гейт),
  RU-контент.
3. **Тёмная тема.** Страница в обеих темах без единой правки состава —
  чистый тест семантик-слоя всей invest-линейки; фиксация в prose стори.
4. **A11y.** Порядок заголовков (h1 страница → h2 секции — против живого
  бага пустых h1 на future/currency, GAP-MAP negatives); прогон axe обеих
  тем; контраст-пары — уже пины атомов, страница ничего не добавляет.
5. **Стори/базлайны.** Сторя паттерна (возможно в docs-разделе patterns);
  базлайны НОВЫЕ ×2 темы (страница длинная — полный кадр); полный compare
  зелёный.
6. **Цикл.** gen → гейты → pathspec → zero-in-flight → push →
