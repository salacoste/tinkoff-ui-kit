## Что уже зафиксировано (13.1, ратифицировано пикселями)

- Триггер avatar-menu: 56px скруглённо-квадратный аватар + подпись
  организации в хедере. Открытое состояние НЕ снято.
- Menu-popover-триггеры повсеместны: «…» кружки, «⋮» кебабы (строки таблиц,
  page-header overflow, плитки избранного).
- В ките НЕТ generic-меню: select/combobox — form-bound listbox'ы (не
  команды/навигация); tooltip/modal — другие контракты. Фактчек ростера
  2026-09-27 это подтвердил.
- Консольный язык: монохромный хром, жёлтый никогда не заливает кнопки.

## Кандидатная поверхность (обсуждение после капчей)

### `tk-menu-popover` — generic-атом (кандидат NEW)

- Механика: overlay-контроллер (AD-12) по select-молде — панель живёт в
  shadow-дереве, Popover API primary, idrefs внутри одного shadow-рута.
- Открытие: декларативный канал `open`/`open-change` (CONVENTIONS §9,
  imperative-исключения только для Toast — тут не нужно).
- Семантика: решается по капчам — APG menu (role=menu/menuitem, стрелки
  рoving, Esc-восстановление фокуса на триггер) если пункты = команды;
  поповер со списком ссылок — если навигация (тогда стрелки не обязаны).
- Триггер: слот (кнопка-кебаб «⋮», «…», кастомный аватар) — сам атом
  триггер не рисует.

### Avatar-menu (кандидат COMPOSITION поверх атома)

- Решение «компонент vs композиция» — по структуре открытой панели из
  капчи: пользовательский блок (имя/организация), группы пунктов,
  сепараторы, выход. Если панель = просто меню с пунктами → композиция;
  если фирменный user-блок → отдельный `tk-avatar-menu` с теми же
  примитивами.
