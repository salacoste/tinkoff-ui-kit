## AC (frozen)

1. **Композиция.** tk-carousel (21.6) + потребительская карточка;
   без новых компонентов/токенов/пинов.
2. **Статы.** Два блока на карточку: цена (число, RU-формат) и
   Δ% (дельта-токен по знаку строки); моноширинных выравниваний НЕ
   вводить — конвенция чисел кита.
3. **Рейл-геометрия.** Карточки одинаковой ширины, скролл-снап рейла
   — контракт tk-carousel (шевроны/точки — его поведение, без правок
   атома); на узкой канве рейл — обычная секция (без колонок).
4. **A11y.** Карусель — region с roledescription (контракт атома);
   карточки — ссылки с полным доступным именем (имя + тикер + статы в
   aria-label ИЛИ видимая семантика); axe обеих тем; единый h1.
5. **Обе темы** без правок состава.
6. **Цикл.** гейты → pathspec → zero-in-flight → push → CI-вердикт →
   close-out; урок 23.4.
