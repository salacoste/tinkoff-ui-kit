## AC (frozen)

1. **Атом.** `tk-publisher-header`: слот `avatar` (круглый носитель —
  потребитель; кит рисует круглую рамку-плейсхолдер по замеру), проп
  `name` (+ слот-оверрайд, молд heading), проп `meta` для строки
  подписчиков («133,1K подписчиков» — формат консьюмера, кит не
  форматирует счётчики), верификационные плашки и follow-кнопка —
  слоты (см. AC3/AC4). STATELESS, event-map no-entry (прецедент
  tk-footer).
2. **Замер.** Геометрия/цвета по captures-v4 при исполнении: размер
  аватара, гэпы, типографика имени/meta (кандидаты — heading/body
  ступени), жёлтая пилюля = tk-button primary consumer-сторёно
  (ожидаемо по 22.6-прецеденту пары). Девиации — в шапку css.ts.
3. **Верификационные плашки.** Круглые носители-чипы рисует кит
  (геометрия/токены по замеру); ГЛИФЫ (щит/галка) — слот-контент
  потребителя: у кита нет иконой системы (zero-media), первый
  потребитель — сторя с токен-фигурами. Пин количества слотов
  (`badge` ×2 повторяемый) в юнит.
4. **Follow.** Слот `action` — кнопка потребителя (tk-button primary);
  кит владеет только раскладкой. БЕЗ follow-state, БЕЗ событий.
5. **Токены/хуки.** Семантики существующие; хуки
  `--tk-publisher-header-*` по замеру (точный набор — пин в юните);
  тёмная тема ремапами, ноль веток.
6. **Стори.** Песочница (полный заголовок) + варианты (без плашек,
  без follow, длинное имя, обе темы) + API. Имя/счётчики ВЫМЫШЛЕННЫЕ
  (ПД-гейт). Базлайны НОВЫЕ ×2 темы.
7. **Тесты.** Unit: слоты/пропы/presence-молды, css-пины, stateless
  no-channel, hidden-guard рост. Полный compare зелёный.
8. **Цикл.** gen → гейты → pathspec → zero-in-flight → push →
   CI-вердикт → close-out штамп.
