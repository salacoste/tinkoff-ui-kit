## AC (frozen)

1. **Атом.** `tk-quote-chip` (`packages/components/src/quote-chip/`):
  props `ticker` (строка, обязательна), `name` (опц. — title/aria),
  `price` (строка — форматирование консьюмерское, кит НЕ парсит),
  `delta` (строка со знаком, напр. «+3,8%» / «−0,12%»), `direction`
  НЕ заводим — знак в строке уже несёт семантику отображения (цвет
  выводится из знака первого символа: +/−; без знака = нейтрально),
  `href` (опц. — чип становится ссылкой на инструмент; живое = чип
  кликабелен), `logo` — слот (круглый лого-раундэл; пусто = буквенный
  раундэл из первой буквы ticker, молд карусели).
2. **Формы.** Один элемент, форма геометрией слота/CSS-хуков:
  (a) инлайн-чип `$TOKEN` (синий текст, без заливки — live-форма в
  теле поста; `variant="inline"`); (b) мини-котировка — раундэл +
  жирная цена + цветная Δ% (`variant="pill"` default, светлая
  бежевая/серая подложка по замеру); (c) attached-quote бокс —
  светло-серый скруглённый контейнер лого+цена+дельта пост-вложения
  (`variant="box"`). Overflow-pill «Ещё N» = `variant="overflow"`
  (светло-голубая pill, счётчик обязательным контентом слота).
  Тикерная лента = НЕ отдельный элемент: полоса чипов рендерится
  consumer-контейнером/карусельной механикой (tk-carousel для карточек
  уже есть; горизонтальный скролл-ряд чипов — тот же паттерн, спека
  НЕ минтует rail-элемент).
3. **Цвета/токены.** Δ% — существующие `--tk-color-delta-positive` /
  `--tk-color-delta-negative` (минта нет); инлайн `$TOKEN` —
  существующий link-синий. Хуки `--tk-quote-chip-{fill,radius,gap,
  text,delta-size}` с дефолтами из замеров. DECIMAL: кит пинит одну
  конвенцию — RU запятая (negative finding GAP-MAP: дрейф «17.25%»
  vs «16,75%» на живом — в прозу стори, значения консьюмерские).
4. **A11y.** Чип-ссылка = настоящий `<a>`; без href — нейтральный
  span (display-only); дельта-цвет ДУБЛИРУЕТСЯ знаком строки (цвет
  не единственный носитель); axe-чистота обеих тем.
5. **Стори.** песочница (все 4 варианта × дельты +/-/нейтрально) +
  демо «тикерная лента» (10 чипов в скролл-ряду, заземление
  research-хаба) + демо «чипы в теле поста» (инлайн + pill ×2 +
  overflow «Ещё 6») + API. Dark — штатными парами.
6. **Тесты.** Unit: 4 варианта, знак→цвет, слот лого/буквенный
  раундэл, href/без-href, css-пины; hidden-guard рост; axe; визуальные
  базлайны НОВЫЕ, полный compare зелёный.
7. **Цикл.** gen → гейты → pathspec-коммит → zero-in-flight → push →
   CI-вердикт по run id → close-out штамп.
