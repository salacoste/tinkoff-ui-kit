  потребителя поверх существующих чипов (не владение чарта); интерактив
  (crosshair/tooltip/zoom/live) — НЕ китовский.

## AC (frozen)

1. **Атом.** `tk-chart`: массив точек (значение + опциональная метка времени)
  → SVG (polyline/area path), STATELESS — ноль событий, ноль канала (молд
  tk-rating: value-in→graphics-out). Серии: линия + градиентная заливка под
  ней (градиент — замер стопов при исполнении; кандидаты — существующие
  invest-стопы 22.5, минт только при расхождении, девиации записываются);
  пунктирная reference line (проп значения — горизонталь); опциональный
  статичный бейдж последнего значения (чёрная пилюля — замер геометрии).
  ViewBox-масштабирование; высота — хук; ширина — 100% контейнера.
2. **Оси/сетка.** Сетка по горизонталям (тихая, замер цвета); ось Y:
  3–5 тиков, ЧЕЛОВЕЧЕСКИ отформатированные (сокращения тыс./млн при
  переполнении; RU-конвенция запятой — пин против живого дрейфа); ось X:
  метки точек по замеру (частота опциональным пропом). Текст осей —
  типографика по замеру (кандидат body-s / mono по живым цифрам).
3. **Токены/хуки.** НИ ОДНОГО сырого значения в SVG-атрибутах напрямую —
  только через CSS custom properties листа (`fill: var(--tk-...)` — FR-1
  на SVG в силе). Хуки `--tk-chart-*` (серия, заливка-стопы, сетка, ось-текст,
  reference, бейдж-пара, высота) — точный набор по замеру, пин количества в
  юнит-тесте. Тёмная тема — ремапами семантик, ноль веток темы.
4. **A11y.** role="img" self-assert + aria-label по пропу (текст тренда —
  ответственность потребителя, кит даёт каркас: «график, N точек, последнее
  значение X» при заданном формате); SVG title/desc; анимаций нет (статичен
  по определению — reduced-motion тривиален).
5. **Стори.** Песочница (1 серия) + варианты (рост/падение/плоская,
  с/без reference, бейдж, переполнение оси Y) + тёмная тема + API. Данные
  ВЫМЫШЛЕННЫЕ (ПД-гейт). Базлайны НОВЫЕ ×2 темы; полный compare зелёный.
6. **Тесты.** Unit: клампы пустых/одноточечных данных, форматтер оси
  (запятая, сокращения), css-пины (токены в fill/stroke, хук-набор),
  stateless no-channel, role/aria-каркас. Полный compare зелёный.
7. **Цикл.** gen → гейты → pathspec → zero-in-flight → push →
   CI-вердикт → close-out штамп.

## Out of scope

- Crosshair, hover-tooltip, zoom/pan, live-обновления, индикаторы (RSI и
  проч.), типы кроме линии/области (свечи/бары объёмов — по отдельному
  рулингу), вертикальная навигация по оси, анимация отрисовки, тулбар
  таймфреймов как китовый компонент (композиция в стори из существующих
  чипов), терминальный хром (imagery-only, DOM-каптуры нет).
