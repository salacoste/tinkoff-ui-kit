## AC (frozen)

1. **Атом.** `tk-empty-state` (`packages/components/src/empty-state/`):
   структура — диск-иконка → заголовок → описание → действие. Слоты:
   `icon` (дефолт — пустой диск, консьюмер кладёт свою иконку), свойство
   `heading`, слоты `description`, `action` (критично: действие = ССЫЛКА
   по живому заземлению — слот, не кнопка-атрибут; кнопка допустима
   слотом тем же механизмом). Выравнивание центр, вертикальный ритм
   стеком.
2. **Геометрия/токены.** Таблица «capture → токен» при исполнении по МОЕМУ
   пиксель-замеру обоих заземлений (captures-v3/admin компакт + captures-v4
   favorites): диск ≈96–120 (замер), радиус карточки (если паттерн-обёртка
   рисует карту — в атоме НЕ рисуем: атом = содержимое, карту даёт
   консьюмер), крюк-слой `--tk-empty-state-*` (диск-заливка, диск-размер,
   ритм). Дефолт без карты — заземление favorites рисует карту паттерном.
3. **Размеры.** Один размер атома (компактность = консьюмерский контейнер);
   `size="compact"` НЕ заводим без второго живого заземления в одном
   паттерне (19.1-урок: не множить режимы без материала).
4. **Стори.** (a) песочница — слоты/события нет (атом пассивный); (b) демо
   «Здесь пока пусто» — заземление favorites: карта + атом + ссылка-CTA;
   (c) админ-компакт паттерн (926×258 молд) рядом — двойное заземление
   одной анатомии; (d) dark. RU контент, вымышленный.
5. **Тесты.** Unit: слоты-рендер, heading-свойство, дефолт-диск, хуки-пины
   css.ts; axe (заголовок не orphaned — секция с aria-label? замер:
   живое = простой блок; role не выдумываем — discussion-паттерн не
   требуется, heading-уровень консьюмерский); hidden-guard рост;
   визуальные базлайны НОВЫЕ, полный compare зелёный.
6. **Цикл.** `pnpm gen` → гейты → pathspec-коммит → zero-in-flight → push →
   CI-вердикт по run id → close-out штамп.

## Out of scope

- Иллюстрации-картинки (живое = иконка-диск, не иллюстрация — 404-паттерн
  с иллюстрациями живёт отдельным кандидатом P11).
- Кнопка-CTA как атрибут атома — только слот (живое = ссылка).
- `size`-варианты, skeleton-empty гибриды, zero-result поиск-паттерн
  (не заземлено в этом раунде).

## Risks / notes

- Консьюмер-разделение «атом без карты / паттерн с картой» может дать
  визуально «висящий» атом в песочнице — стори рисует карту на уровне
  канвы-декорации с FLAG-комментарием (проза-литерал, не токен).
- favorites-замер «синяя ссылка»: токен ссылки уже существует — НЕ минтить
  новый (у кита link-цвет закреплён); таблица это зафиксирует.
