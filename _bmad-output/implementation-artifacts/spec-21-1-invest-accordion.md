## AC (frozen)

1. **Атом.** `tk-accordion` (контейнер: разделители, вертикальный ритм) +
   вспомогательный `tk-accordion-item` (header-строка + панель), каталог
   `packages/components/src/accordion/`, экспорт в barrel. Слоты: item —
   `summary` (строка-вопрос) + default (тело ответа); контейнер — items.
   Декларативный канал: `open` (boolean, per-item) + событие
   `open-change` (CONVENTIONS §9; composed+bubbles; молчание при первом
   рендере — флаг `#hasRenderedOnce`, руление 19.1-5).
2. **Поведение (APG disclosure).** Header = `<button>` с `aria-expanded`
   (ставит атом); Enter/Space toggle; клик toggle. БЕЗ `aria-controls`
   (панель — shadow-ребёнок; прецедент tk-select/menu-popover). Панель =
   `role="region"` + `aria-label` из summary (когда открыт). Независимые
   строки (живой паттерн: каждая раскрывается сама); режим `single`
   (аккордеон-собственно) — свойство контейнера, НЕ этого раунда (out of
   scope, если замер не найдёт живой single-инстанс).
3. **Токены/хуки.** Слой `--tk-accordion-*` (радиус карточки, разделитель,
   chevron-цвет, ховер строки) поверх существующих нейтралей; высота строки
   — A11y-пол 44px минимум (живое ≈56–64 больше пола — ок); таблица
   «capture → токен» в Implementation Notes при исполнении. Жёлтый НЕ
   используется (панель чисто нейтральная).
4. **Стори.** Докс-секция: (a) песочница с логом open-change; (b) демо
   «Частые вопросы» — заземление bonds-list/SBER: 3–4 строки, одна открыта
   по умолчанию; (c) открытые состояния ×2 + dark; контент RU, вопросы
   финансово-бытовые ВЫМЫШЛЕННЫЕ (закон ПД: ничего дословно из капч с
   числами). component-search добавлен.
5. **Тесты.** Unit: toggle/клавиатура/aria-expanded/open-change-молчание
   при mount/hover-пины css.ts; axe на открытом; import-boundaries +
   hidden-guard рост (листы accordion.css.ts); визуальные базлайны НОВЫЕ
   (первичный минт), полный compare зелёный (2182+N).
6. **Цикл.** `pnpm gen` (CEM + React-обёртки семейства) → гейты EXIT 0 →
   pathspec-коммит → zero-in-flight (вердикт рана 72939e9 снят) → push →
   CI-вердикт по run id ПОСЛЕ факта → память + CLAUDE.md close-out штампом.

## Out of scope

- Режим `single` (ротация открытых) — нет живого заземления в капчурах.
- Анимация раскрытия (height transition) — FLAT-цензус: сначала без
  анимации; если замер найдёт живую анимацию — отдельным раундом.
- Nested accordions, аккордеон-фильтры (мобайл-паттерн) — не заземлено.
- ТЖ-стороны (tj-обёртка не нужна: банк-атом потребляется ТЖ-паттернами
  напрямую, как tk-menu-popover в 19.1).
