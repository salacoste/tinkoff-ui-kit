# pillkit-tj-tokens

Дизайн-токены ТЖ-под-кита [pillkit](https://github.com/salacoste/tinkoff-ui-kit) —
редакционный язык «Тиньков Журнала»: custom properties `--tj-*` со светлой базой
на `:root` и нативной тёмной темой на `[data-tj-theme="dark"]` (контракт
`auto`/`light`/`dark`). Семейство ТЖ не зависит от банковского кита ни одним
импортом (FR-17) и потребляется отдельно от него.

Статус: токен-слой сгенерирован (story 15.2) из
`ux-designs/ux-tj-kit-2026-09-28/DESIGN.md` вторым входом того же генератора:
96 светлых токенов + 11 семантических тёмных оверрайдов с нативной тёмной
ногой; канонический список — `src/TOKENS.md`. Шрифтовая политика вокруг
слотов `--tj-font-*` — story 15.3 (раздел «Шрифты» ниже).

> **Неофициальный учебный проект.** pillkit — независимое воссоздание языка
> дизайна в учебных целях; не аффилирован ни с какой компанией и не использует
> чужие товарные знаки в наименовании. Полный дисклеймер — в README репозитория.

## Установка

Дистрибуция — только через [GitHub-репозиторий](https://github.com/salacoste/tinkoff-ui-kit),
в npm пакеты не публикуются. Рецепт workspace-линка — в README репозитория
(«Быстрый старт»): клонировать репо (пин релизного тега, например
`--branch v1.4.0`), добавить его
`packages/*` в свой `pnpm-workspace.yaml`, собрать, затем — только семейство ТЖ:

```bash
pnpm add -w pillkit-tj-tokens --workspace
```

## Использование

```ts
import 'pillkit-tj-tokens/tokens.css';
```

Тёмная тема — атрибутом на корне приложения: `<html data-tj-theme="dark">`
(или `auto` — следует системной схеме).

## Шрифты

Двухсемейный шрифтовой контракт (FR-20) живёт в двух слотах; с 18.3 действует
модель «сплит» — сериф кит дистрибутирует сам, гротеск остаётся слотом и
рецептом:

- `--tj-font-ui` — гротеск UI и заголовков: стек начинается с **Graphik**,
  за ним открытые фолбэки (`Inter`, системные, `sans-serif`). Байтов Graphik
  в ките НЕТ и не будет: стандартная EULA Commercial Type не даёт прав на
  перераспределение файлов. Держатели лицензии используют
  face-рецепт (закомментированный) в
  [`pillkit-tj-fonts/fonts.css`](../tj-fonts/fonts.css) или папку
  `packages/docs/src/local-fonts/` для self-hosting в доке; у остальных —
  честный открытый Inter (кириллица + латиница).
- `--tj-font-reading` — антиква читального регистра: стек начинается с
  **XCharter** (затем `Charter`, `"Bitstream Charter"`, `"PT Serif"`,
  `Georgia`, `serif`). XCharter — свободное Charter-идиомное семейство
  С кириллицей (оригинальный Bitstream Charter латинский, 228 глифов);
  распространяется китом под условиями Bitstream Charter.

Читальный сериф подключается одним импортом рядом с токеновым листом:

```ts
import 'pillkit-tj-tokens/tokens.css';
import 'pillkit-tj-fonts/fonts.css';   // XCharter ×4 (400/700, прямое/курсив)
```

Носитель — отдельный пакет [`pillkit-tj-fonts`](../tj-fonts) (Daytona-молд,
смешанная лицензия, вербатим-грант Bitstream и атрибуция Panov/Sharpe — в
его `LICENSE-FONTS.md`); сам ЭТОТ пакет и вся тройка `pillkit-tj-*`
остаются **zero-fonts по тесту** `tests/tj-fonts-policy.test.ts` — ни одного
шрифтового face-объявления и ни одного байта шрифтов в их дереве:
дистрибуция живёт строго в носителе (инвариант 15.3/OQ-8 сохранён,
«осознанный PR» состоялся в 18.3).
Визуальный харнесс пинит оба слота на локально раздаваемые открытые лица
(Inter / PT Serif) — рендеры детерминированы на любой машине, с
лицензионными шрифтами или без.
