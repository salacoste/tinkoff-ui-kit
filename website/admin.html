Family showcase · console register

The Admin family

The same 46 tk-* atoms, spoken with a console accent. This register is aimed at internal tools, back-office consoles and dashboards — dense data surfaces, chrome tabs with counts, and state feedback on every async action. One token layer still rules everything: flip the theme toggle in the header and the whole console re-themes. Every demo below is live.

Data surfaces

The heart of a console: a typographic table with financial cells, plus the badge scale for statuses a table cell cannot tint. Rows are inert here; href turns them into links when a registry needs navigation.

Confirmation flows

Destructive console actions confirm in a modal, then report the outcome in a toast — focus returns to the trigger either way, so keyboard operators never lose their place in the queue.

Cancel documents

Cancel 2 selected

Esc and the scrim close safely; the destructive button carries the consequence, not the layout.

Outcome toasts

Fire success toast Fire failure toast

the shared stack keeps the newest three; a longer duration fits errors that need reading.

Code 
<tk-modal id="cancel" heading="Cancel 2 selected documents?">
  <p>The counterparties will be notified. This cannot be undone in the queue.</p>
  <tk-button slot="actions" variant="secondary">Keep them</tk-button>
  <tk-button slot="actions" variant="primary">Cancel documents</tk-button>
</tk-modal>

<script type="module">
  document.getElementById('cancel').open = true;
</script>

Wayfinding

Deep consoles need both scales: the breadcrumb says where in the hierarchy you are, the pager says where in the dataset — one event each, no page reloads.

Trail + pager

show-more renders the «load next chunk» bar alongside page turns — pick one per real dataset, not both.

Code 
<tk-breadcrumb id="crumbs" label="You are here"></tk-breadcrumb>
<tk-pagination count="48" default-page="3" show-more more-label="Load 20 more"></tk-pagination>

<script type="module">
  document.getElementById('crumbs').items = [
    { label: 'Console', href: '/tinkoff-ui-kit/admin.html' },
    { label: 'Payments' },
    { label: 'October 6 registry' },
  ];
</script>
