Showcase · invest family

Trading & research surfaces

Market-data chips, instrument identity cards, static SVG charts, financial tables and the terminal order ticket — the invest atoms for quotes, research pages and trading UIs. They live in the bank family package and theme with the same --tk-* token layer, so one toggle re-skins the whole dashboard. All instruments, prices and limits on this page are fictional demo data.

Reach for this family on dashboards, quote tickers, research longreads and trading terminals. Note the deliberate exception: Buy/Sell CTA fills ride the theme-invariant trade tokens — the measured terminal behavior, kept identical in light and dark.

Market data chips

tk-quote-chip is the whole live market-chip family in one atom: a mini quote (pill), an inline $TOKEN inside prose, a boxed single-quote widget and the “More” overflow pill. The delta tone is derived from the sign of the string — color is never the only carrier of meaning. tk-badge adds the text-only financial tones (positive/negative) next to plain marketing pills.

Instrument page

tk-instrument-hero is the identity card of an instrument page: name and ticker over an asset-class gradient (stock / bond / dark / light), an optional metric block, a round logo disc and the consumer’s favorite-star slot — the kit never owns portfolio state. Below it, tk-publisher-header carries the research-desk row: avatar, verified badges and a subscribe button that stays consumer-side.

Static charts

tk-chart renders the instrument page’s price chart as pure SVG: an array of points in, graphics out — no state, no events. The fill gradient follows the instrument family tone; grid, dashed reference line and the last-value badge are optional layers. The Y axis formats “human” ticks (NBSP grouping, decimal comma, thousands/millions abbreviations) and the element carries role="img" with a derived label.

Financial tables & spec lists

tk-data-table is the catalog table: two-line cells, delta-toned change columns, the whole row as one link with a roving-tabindex keyboard layer. tk-kv-list is the spec list of a bond card — label left, value flush right, hairline dividers and real “?” hint tooltips on the rows that need them.

Code — data table wiring 
const table = document.querySelector('tk-data-table');
table.caption = 'Stock catalog';
table.columns = [
  { key: 'name', header: 'Name', width: '1fr' },
  { key: 'price', header: 'Price', align: 'end' },
  { key: 'change', header: 'Change', align: 'end' },
];
table.rows = [
  {
    href: '/invest/stocks/SBER/',
    cells: {
      name: { primary: 'Sberbank', secondary: 'SBER' },
      price: { primary: '318,44 ₽', secondary: '1 lot = 10 shares' },
      change: { primary: '+12,55 ₽', secondary: '+1,46 %', delta: 'positive' },
    },
  },
];

Terminal ticket

The order-ticket pattern from the kit’s pattern stories: tk-tabs for the order modes (an APG tabs bar — arrows walk the modes, Home/End jump, disabled entries are skipped), numeric fields with stepper buttons that sit deliberately outside the tab order (the keyboard types digits directly; steppers are pointer affordances that disable at the range boundary), a limits strip per side and the Buy/Sell pair on tk-button variants positive/negative. The trade fills are theme-invariant by design — flip the site theme and the pair stays put, exactly like the measured terminal.

Price tickets & card rails

tk-promo-card in its ticket variant is the sidebar price ticket of the instrument page — label, bold value, a full-width primary CTA and a small note. tk-carousel is the snap rail underneath: a native scroll-snap container with chevrons on hover and decorative dot pagination; the cards themselves are plain light-DOM slots, so any card geometry fits.
