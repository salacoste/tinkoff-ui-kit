Торговые и исследовательские поверхности

Рыночные чипы, карточки-герои инструментов, статичные SVG-чарты, финансовые таблицы и терминальный бланк заявки — инвест-атомы для котировок, research-страниц и торговых интерфейсов. Они живут в пакете банковского семейства и темятся тем же токен-слоем --tk-*: один переключатель пересобирает весь дашборд. Все инструменты, цены и лимиты на странице — вымышленные демо-данные.

Семейство — для дашбордов, тикерных лент, research-лонгридов и торговых терминалов. Заметная намеренная особенность: заливки CTA «Купить/Продать» едут на theme-invariant торговых токенах — замеренное поведение терминала, в светлой и тёмной темах одинаковое.

Рыночные чипы

tk-quote-chip — всё живое семейство рыночных чипов в одном атоме: мини-котировка (pill), инлайн-$TOKEN в тексте, вложение-виджет одиночной котировки (box) и пилюля «Ещё N» (overflow). Дельта-цвет выводится из знака строки — цвет никогда не единственный носитель семантики. tk-badge добавляет текстовые финансовые тоны (positive/negative) рядом с маркетинговыми пилюлями.

Тикерная лента — pill-чипы

Ещё 6

Голые чипы на горизонтально скроллящейся полосе; пустой слот лого даёт раундэл из первой буквы тикера.

Чипы в теле поста и бейджи

Референс вставляет тикеры прямо в прозу поста: и — синие, капсом, без подложки.

Инлайн-$TOKEN, текстовые дельта-бейджи и вложение-виджет одиночной котировки (variant box).

Страница инструмента

tk-instrument-hero — карточка-герой инструментальной страницы: имя и тикер на градиенте класса актива (stock / bond / dark / light), опциональный блок метрики, круглый лого-диск и звезда избранного — слот-кнопка консьюмера (кит не владеет состоянием портфеля). Ниже — tk-publisher-header: ряд профиля издателя с аватаром, плашками верификации и кнопкой подписки, состояние которой всегда на вашей стороне.

</tk-publisher-header>

Статичные чарты

tk-chart рендерит чарт инструментальной страницы чистым SVG: массив точек на входе — графика на выходе, без состояния и событий. Градиент заливки следует тону семейства инструмента; сетка, опорная пунктирная и бейдж последнего значения — опциональные слои. Ось Y печатает «человеческие» тики (NBSP-группировка, запятая-десятичная, сокращения «тыс.»/«млн»), сам элемент несёт role="img" с производным aria-label.

Рост — тон stock

Демо-индекс, день reference · badge

Опорная линия внутри диапазона плюс пилюля бейджа последнего значения.

Падение — тон bond

Демо-облигация, день tone: bond

Чарт не знает «зелёное — вверх»: тон выбирает потребитель, геометрия от направления не зависит.

Код — подключение чарта 
const chart = document.querySelector('tk-chart');
chart.points = [
  { value: 101.2, label: '10:00' },
  { value: 102.1, label: '11:00' },
  { value: 101.8, label: '12:00' },
  { value: 103.4, label: '13:00' },
];
// опциональные слои: reference="102" badge  ·  tone="stock|bond|dark|light"

Финансовые таблицы и списки параметров

tk-data-table — типографическая таблица каталога: двухстрочные ячейки, дельта-тона колонки «Изменение», вся строка — область клика единственной ссылки, клавиатурный слой — roving tabindex. tk-kv-list — список «параметр — значение» карточки облигации: серый лейбл слева, значение прижато вправо, разделители 1px и настоящие «?»-тултипы у нужных строк.

Каталог акций

Дельта-тон красит обе строки ячейки; строка без href инертна и пропускается фокусом.

Информация о выпуске

14,70 % 19.06.2027 Фиксированный 74,68 ₽ +2,4 % −1,1 %

Тона значений — контент слота: атом никогда не угадывает тон из текста.

Код — подключение таблицы 
const table = document.querySelector('tk-data-table');
table.caption = 'Каталог акций';
table.columns = [
  { key: 'name', header: 'Название', width: '1fr' },
  { key: 'price', header: 'Цена', align: 'end' },
  { key: 'change', header: 'Изменение', align: 'end' },
];
table.rows = [
  {
    href: '/invest/stocks/SBER/',
    cells: {
      name: { primary: 'Сбербанк', secondary: 'SBER' },
      price: { primary: '318,44 ₽', secondary: '1 лот = 10 акций' },
      change: { primary: '+12,55 ₽', secondary: '+1,46 %', delta: 'positive' },
    },
  },
];

Терминальный тикет

Паттерн бланка заявки из паттерн-историй кита: режимы — tk-tabs (APG-табы: стрелки ходят по режимам, Home/End — в начало/конец, недоступные пропускаются), поля цены и лотов — tk-input со степперами ВНЕ таб-порядка (клавиатура вводит цифры напрямую; степперы — аффордансы указателя, отключающиеся на границе диапазона), внизу — пара «Доступно» + CTA «Купить/Продать» на вариантах positive/negative кнопки. Торговые заливки theme-invariant: переключите тему сайта — пара не изменится, ровно как в замеренном терминале.

Ценовые билеты и карточные рейлы

tk-promo-card в варианте ticket — ценовой билет сайдбара инструментальной страницы: лейбл, жирное значение, CTA на всю ширину и мелкая приписка. tk-carousel — snap-рейл под ним: нативный scroll-snap контейнер с шевронами по ховеру и декоративной точечной пагинацией; карточки — обычные light-DOM слоты, влезает любая геометрия.
