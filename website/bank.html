Family showcase · bank register

The Bank family

The core register of pillkit: the product surfaces of a retail bank — onboarding forms, payment flows, account dashboards and marketing pages. It is 46 tk-* custom elements on one token layer: flip the theme toggle in the header and every demo on this page re-themes through --tk-* custom properties, with zero branches in component code. Everything below is live — type, click and drag.

Inputs & forms

The stateful atoms of onboarding and payment forms. The value/defaultValue contract is frozen: default-value seeds the uncontrolled field, value-change is the single output channel, and error text is a prop, not markup.

Text fields

type, filter and validation text — the field grows with content, no resize handle.

Confirmation code

code mode renders an OTP cell row; the complete event fires when the last cell fills.

Toggles

checkbox for opt-ins, switch for instantly-reversible settings — never both for one rule.
