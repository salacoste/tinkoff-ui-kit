## Recorded choices (the spec's Implementation Notes mandate)

| # | Decision | Choice + rationale |
|---|----------|--------------------|
| 1 | **API-table mechanism** | A generated story per suite («API», `export const Api`) rendered by `packages/components/src/api-reference.ts`, which imports the COMMITTED `custom-elements.json` directly. Autodocs/ArgsTable was rejected: it would fork the API description surface and is not part of the visual harness's baselined story set. The manifest is the API surface of record (AD-1), drift-gated by `check:gen` — the tables cannot disagree with the code. Attributes + property-only channels (from members, statics excluded), events, slots. Manifest descriptions render verbatim (EN jsdoc — the same source that generates React wrappers); page chrome is RU. |
| 2 | **Token-reference generation path** | `packages/docs/src/token-reference.stories.ts` imports the GENERATED typed token maps from `pillkit-tokens` (`src/tokens.ts` — regenerated by `pnpm gen:tokens`, drift-gated by `check:tokens-drift`). Drift is impossible BY CONSTRUCTION: the page renders the same objects the components consume. Includes colors (light/dark side by side incl. alpha-safe swatches), typography (live specimens), radius/spacing/shadows, the z-scale, and motion (sampled bezier profiles + duration bars). |
| 3 | **Docs-site states placement** | On the getting-started index page: interactive component search (`packages/docs/src/component-search.ts`, 19 names, RU empty state «Ничего не найдено. Попробуйте название компонента.») + cold-load skeleton demo matching the page layout (static blocks per the kit's no-shimmer skeleton pattern — reduced-motion-safe by construction). **RULING: Storybook sidebar/manager-chrome search customization is OUT OF SCOPE** — the manager is tooling around the product surface, not a kit surface. |
| 4 | **Theming-guide demo surface** | tk-button exposes NO per-component fill hooks (it consumes semantic tokens directly) — the spec's «button fill channels» example was adjusted to the real equivalents: `--tk-input-fill` (field fill channel) and the charcoal card CTA pair `--tk-promo-card-cta-fill`/`-text`. Recorded in the theming-guide file header. |
| 5 | **Infrastructure** | `tsconfig.base.json` gains `resolveJsonModule` — required for importing the generated manifest from TS. No token, component-behavior, or analyzer-config changes. |
| 6 | **Doc-string defects** | NONE found: the CEM already carried attrs/events/slots for all 19; no jsdoc fix + regen was needed. |
| 7 | **`dist/api-reference.d.ts` in the tarball — ACCEPTED for 5.5** | `packages/components/src/api-reference.ts` compiles to `dist/api-reference.d.ts`, which ships via `files: ["dist"]` but is UNREACHABLE through the exports map (only `.`, `./CONVENTIONS.md`, `./custom-elements.json`). Review finding F2 — accepted for this story; revisit at 5.7 packaging: either exclude from `files`, or tsconfig-exclude the file (trade-off: an exclude also drops it from type-checking — the stories importing it are checked by the ROOT tsconfig, so the helper's own errors would surface only there, weakening the net). |
