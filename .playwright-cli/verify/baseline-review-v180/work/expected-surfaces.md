## Общие инварианты кадра (все 7 групп)

1. **Кадр = preview-canvas стори, БЕЗ Storybook-менеджера.** Харнесс
   (`tests/visual/visual.spec.ts`) грузит `iframe.html?id=…` и снимает
   `page.locator('body')` — левой навигации/поиска Storybook в кадре НЕТ.
   Не считать их отсутствие дефектом. (Коррекция исходного предположения
   «нав/поиск слева» — см. расхождение R1 в отчёте.)
2. **Дисклеймер-баннер сверху почти каждого кадра**: «Неофициальный учебный
   проект. pillkit — независимое воссоздание дизайна Т-Банка (экс-Тинькофф)
   в учебных целях…» — постоянный декоратор превью (`.storybook/preview.ts`),
   тематированный. ИСКЛЮЧЕНИЯ: обе getting-started-страницы (банк и ТЖ) —
   баннер подавлен, дисклеймер отрисован инлайн-боксом внутри страницы.
3. **Тема отличима фоном канвы и инверсией текста.** Канвы стори красятся в
   `--tk-color-surface-base`: light **#FFFFFF**, dark **#1A1A1A**. Текст
   primary: **#333333** / **#FFFFFF**; secondary: **#616871** /
   полупрозрачно-белый **#FFFFFFB3**. Пара light/dark одного id обязана
   отличаться именно фоном страницы — иначе тема не перевернулась.
4. **Жёлтый акцент theme-invariant**: `--tk-color-yellow-100 #FFDD2D` в обеих
   темах одинаковый — жёлтые треки/капсулы/кнопки не меняют цвет между
   кадрами пары.
5. **Контент — русский**; исключение — API-стори: описания в таблицах
   вербатим-английские (JSDoc → CEM), страница-хром русский.
6. **Моно-шрифт запинен харнессом** (JetBrains Mono, локальный) — `<code>`/
   `<pre>`-блоки (хуки, команды, логи) рендерятся моноширинно и одинаково.
7. **API-стори (общий шаблон)**: h1 «API — <tag>», вводный абзац, секции
   «Атрибуты и свойства», «События», «Слоты», «Каналы темизации» — таблицы
   из CEM-манифеста; на синем «чипе»-строке имена атрибутов моноширинно.

Справочные цвета (light → dark): border-default #E7E8EA → #FFFFFF24
(композит ≈ #313131); border-strong #CBCFD3 → #FFFFFF3D; surface-muted
#F5F5F6 → #222222; surface-field #ECF1F7 → #FFFFFF1A (композит ≈ #313131);

## G1 — RangeSlider (10 PNG; spec 26.1)

Семейство: одноручковый слайдер суммы. Геометрия (рулинг мейнтейнера
2026-10-05, китовые регистры): **трек 4px** full-width пилюля
(border-default), **заполнение yellow-100 #FFDD2D**, **ручка — круг 20px**
yellow-100 с внешним кольцом 2px ink-300. Хедер поля: подпись слева
(text-secondary), значение справа (text-primary, bold-класс), 8px до трека;
голый инстанс (aria-label) — только трек, без хедера.

- **playground «Песочница»**: h1 «RangeSlider», интро-абзац (упоминает
  `tk-progress-bar` 4px, круг 20px, HOLD → 24T), затем 2 инстанса:
  «Сумма перевода» → значение 20; «Доля портфеля, %» → значение 35.
- **variants «Варианты»**: матрица 5 figure с подписями-figcaption:
  1) голый слайдер (трек без заголовка); 2) «Сумма перевода» + plain
  readout 20; 3) «Лимит карты» → readout **«210 000 ₽»** (formatter,
  шаг 30 000); 4) слоты: подпись «Срок аренды, мес.», значение-слот
  **«свой текст»**; 5) disabled «Процент кэшбэка» 3 — вся строка 40%
  прозрачности.
- **calculator «Калькулятор (паттерн)»**: карточка на surface-muted
  (light #F5F5F6 / dark #222222, radius-lg): h2 «Накопительный счёт
  „Про запас“», пара крупных чисел **«150 000 ₽» / «1 050 ₽»** (readout
  суммы и дохода), слайдер «Сумма счёта / доход в месяц» с formatter ₽,
  hint «Расчёт условный: демо-ставка 0,7% в месяц…», жёлтая CTA-кнопка
  **«Открыть счёт»** (yellow-100, тёмный текст).
- **accessibility «Доступность»**: интро-абзац (нативный input type=range,
  PageUp/PageDown ±10 шагов), h2 «Чек-лист: только с клавиатуры», таблица
  строк: Tab/Shift+Tab, ←/→ (и ↑/↓), Home/End, PageUp/PageDown,
  Скринридер; ниже один рабочий инстанс «Сумма перевода» → **«4 500 ₽»**
  (сетка 1000–20000, шаг 500).
- **api «API»**: «API — tk-range-slider»; таблицы атрибутов label/min/max/
  step/defaultValue/disabled + aria-label-форвард (строка ariaLabel — след
  axe-фикса 26.1, манифест рос: базовая длина страницы ≈1327px в light).

Light/dark: жёлтые fill/ручка неизменны; серый трек инвертируется
(#E7E8EA → светлее фона); канва/текст по инварианту 3.
