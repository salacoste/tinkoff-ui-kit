# Group VI ledger — режимные поверхности 10.1–10.4 на SWEEP-движке (история 11.1)

Спецификация 11.1 закрыла долг 6.5/8.1: режимные дельты 10.1–10.4 получили
движковые ноги и ledger-строки. `tests/visual/a11y-sweep.spec.ts` нёс
**Group VI** реестра — по ВТОРОЙ строке на компонент (прецедент group V:
v1-строки выше остаются v1-контрактом, режимные строки — своим): 6 ног
реестра (2 строки × обход×2 темы + скан) + 5 режимных targeted-ног + 1 нога
7.2(b) в `tests/visual/cookie-banner.spec.ts` = **12 новых ног, все зелёные**
(файл целиком: 99 passed). Легенда: **sweep** = Group VI-ноги
`tests/visual/a11y-sweep.spec.ts`, **axe** = сгенерированные покомпонентно-
тематные ноги `tests/visual/visual.spec.ts`, **RM** =
`tests/visual/reduced-motion.spec.ts` (story-loop: каждая история × тема —
новые фигуры существующих историй подъезжают автоматически). Каждый
file:line-указатель открыт при прогоне; тела проверены.

Расширения движка, привезённые этой проходкой (с основаниями):
- **Граница грамматики `&args=`** — канал несёт ТОЛЬКО ASCII: булевы,
  числа и ASCII-строки применяются (пробел через %20, `:` как %3A — тоже);
  мультибайтное UTF-8 значение молча ОТБРАСЫВАЕТСЯ парсером Storybook
  (`error:abc def` рендерится, `error:Подтвердите…` не доходит до рендера
  ни в raw, ни в percent-encoded; зонд на собранном бандле, 2026-09-26).
  RU-строки ездят через element property API (тот же реактивный проперти,
  та же ветка рендера) — mold: нога `tk-checkbox [error]`. Граница
  задокументирована в docblock хелпера `openStoryArgs` и в самой ноге.
- **7.2(b) обратный вход cookie-баннера** — чтение «одна жать Shift+Tab =
  accept» ОПРОВЕРГНУТО измерением: порядок от body — слоттированная ссылка
  → демо-кнопка story-хрома → body (переходно) → «Хорошо». Нога ride'ит
  mold 8.1: ограниченный обход; ПЕРВЫЙ стоп уже внутри top-layer карточки.
- **Три демо-фигуры в «Доступность»-историях** (stepper subtitle, qr-block
  page-copy, button href) — одобрено оркестратором: копии контента
  Variants/VariantsAndSizes дословно (те же подписи/пропсы), чтобы у каждой
  поверхности был ИСПОЛНИМЫЙ URL для run-sheet'а мейнтейнера.

| R1 | «Одна жать Shift+Tab = accept» на открытом cookie-баннере. | ОПРОВЕРГНУТО измерением (ссылка → демо-кнопка → body → «Хорошо»); нога 7.2(b) — ограниченный обход mold 8.1, обратный вход подтверждён (первый стоп внутри карточки). |
