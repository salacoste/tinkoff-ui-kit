## 1. tk-filter-chips

- Обход: Tab на первый чип → стрелки по ряду → Space (выбор) → Enter на «Ещё» → Enter на «Индексы» → Esc
- Ожидаемые анонсы (RU, дословно из протокола):

  4. Enter на «Ещё» → «Ещё, развёрнуто, меню»; фокус: «Стратегии, пункт меню-переключатель»
  5. Enter на «Индексы» → «Индексы, отмечено»; меню свёрнуто, фокус: «Ещё, кнопка»
  6. Esc → закрытие без изменения значения, фокус на «Ещё»
