# Group VII ledger — консольное семейство 13.2–13.3 на SWEEP-движке (история 14.1)

Спецификация 14.1 закрыла свип-долг консольного семейства (зеркало 11.1
для 10.x): три новые истории 13.2/13.3 получили движковые ноги. `tests/
visual/a11y-sweep.spec.ts` нёс **Group VII** реестра (прецедент второй
строки на компонент — v1/v2-строки выше не тронуты): **9 новых ног**
(3 walk × 2 темы + 3 deep-scan), все зелёные; файл целиком **108 passed**
(2026-09-27, собранный бандл доков). СТОПЫ ИЗМЕРЕНЫ движком: walk-нога
пинит точное число кит-стопов (roving tabindex = 1 на группу табов),
scan-нога — нижнюю границу поверхностей; зелёный точный ассерт = сам
замер.

Легенда (как в group-VI): **sweep** = Group VII-ноги `tests/visual/
a11y-sweep.spec.ts`, **axe** = сгенерированные покомпонентно-тематные
ноги `tests/visual/visual.spec.ts` (базлайны консольного семейства
захвачены в 13.2/13.3 — ноги axe уже существуют и зелёные), **RM** =
`tests/visual/reduced-motion.spec.ts` (story-loop: новые фигуры
подъезжают автоматически), **UNIT** = vitest пакета components, **live**
= ножки в поведенческих spec-файлах. Каждый file:line-указатель открыт
при прогоне; тела проверены.

Записанное решение (спека 14.1, раунд линзы 1): v2-страницы паттернов
(Console chrome, Data surfaces) НА РЕЕСТРЕ НЕ СТОЯТ — линия 8.1 держит
(свип ходит по каноническим историям компонентов; страницы доков едут
axe-ногами визуального набора ×2 темы + SR-протокольными таблицами ВНУТРИ
страниц, задача 3 спеки 14.1).

мейнтейнерская сторона (§8.1.4), пакет v1.3.0 — 14.2.
