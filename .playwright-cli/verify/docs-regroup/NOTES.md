# Docs navigation regroup — «Components v2» → Guides / Patterns (interlude round 2, 2026-09-28)

Post-v1.3.0 polish round, item 1 of 3 (maintainer sanction «lets continue to improve» →
«Полиш-раунд сейчас (автономно)»). The seam was named in the 2026-09-28 architecture
Q&A: the docs nav group `Components v2/*` was named after the BUILD WINDOW (the v2
epics), not after what the pages are — a naming artifact, since v1 components fold
their docs into the component stories while v2 components carry two surfaces.

## What the 11 pages actually are

- 9 overview pages (what/when/not-for + live usage + theming + a11y + CEM API table),
  one per v2-family surface: Combobox search, Cookie banner, Data table, Filter chips,
  Mega nav, Pagination, QR block, Stepper, Store badges. The interactive suites live
  separately at `Components/*` (component-package stories, baselined).
- 2 composition pattern pages owning no element: Console chrome, Data surfaces.

## Decisions

| Decision | Rationale |
|---|---|
| `Guides/*` for the 9 overviews, `Patterns/*` for the 2 compositions | Semantic, stable against future windows (no more generation-named groups); page-kind split matches the actual asymmetry |
| Story display names UNTOUCHED (only the group prefix) | Minimal churn: PNG baselines rename prefix-only; search titles keep working |
| 28 baselines git-mv'd byte-identical (1.8 platform-neutral precedent) | Pure story-id rename — zero pixel change, provable by the green compare runs |
| cookie-banner page PNGs re-taken (delete + update, the 1.5% rule) | Its rendered anchor text changed: «Components/Cookie banner» → exact suite casing «Components/Cookie Banner» |
| Cross-link jsdoc texts corrected to exact suite titles | ComboboxSearch, Cookie Banner, DataTable, FilterChips, QrBlock, StoreBadges — were approximations with spaces |
