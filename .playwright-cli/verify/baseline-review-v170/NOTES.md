## 4. Два dark-outlier'а — расследование и диспозиции

Паспорт яркости поднял 2 anomalously-ярких dark-кадра. Полная цепочка
(пиксели → source → живой DOM-проба на приватном порту 6483 статического
SB-билда, пробы `bc-probe{,2,3}.mjs` здесь же):

1. **`visual-components-figure--playground-dark` (mean 0.587)** —
   ДИСПОЗИЦИЯ: контентный, by-design. Источник: `IFRAME_STUB` стори
   («iframe stub — srcdoc SVG on system colors, theme-adaptive, no hex»,
   figure.stories.ts:48-49) красит `html{background:Canvas}` — системный
   цвет, который в headless-харнессе белый независимо от `data-theme`.
   Крупные 16/9 iframe-боксы демо-медиа белы в ОБЕИХ темах (намеренный
   нейтральный стаб, ПД-гейт). Живой рендер байт-идентичен базлайну
   (дифф 0.36%). Плюс жюттеры — см. флаг ниже.
2. **`visual-components-breadcrumb--playground-dark` (mean 0.436)** —
   сначала выглядел как «светлая панель в тёмном кадре»; форензика
   разложила на ДВЕ составляющие: (а) СИНИЕ ссылки #619BF2 = dark-link
   токен крошек (корректно), тёмный канвас #1A1A1A 60% кадра (корректно);
   (б) **БЕЛЫЕ ЖЮТТЕРЫ страницы** — см. флаг §5.

## 5. ФЛАГ на арбитраж мейнтейнера (единственный открытый)

**Белые жюттеры dark-плейграундов tk-breadcrumb / tk-figure.** Обе стори
центрируют канвас `max-width: 820px; margin: 0 auto` и НЕ ставят фон
html/body; фон канваса = `var(--tk-color-surface-base)` (dark #1A1A1A), но
за пределами 820px остаётся браузерный дефолт (белый) — в dark-ногах
визуального харнесса кадр = тёмная колонка 820px в белых полях (~230px
с каждой стороны + низ). Измерено: v1-эра следует идиоме full-bleed
(button/input/accordion/badge playground-dark mean 0.130–0.144 —
полностью тёмные); chart/publisher-header окна 23 тоже full-bleed
(0.155–0.156). Белые жюттеры — отклонение двух новых сторей 24b от
китовой идиомы, НЕ продукт-дефект компонента (потребительский рендер
не затронут; это фрейминг стори-канваса в харнессе/доках).

Предлагаемый фикс (1 строка на стори, токен-ONLY — FR-1): в
`canvasStyles` сторей добавить `body { background:
var(--tk-color-surface-base); }`; последствия для базлайнов: 2 dark-PNG
переминт ЯВНО (rm → update; дельта >> порога), light-пары ожидаются
байт-идентичными (surface-base light = #FFFFFF — дефолт белого); полный
compare + CI обязателен. НЕ исполнено присестом — источник = src стори,
вне санкционированного скоупа confirm-only. Решение за мейнтейнером:
фикс теперь / в следующем окне / принять как есть.
